# Football Trivia

A light, projector-friendly football trivia board built with Vite and React.

## Run

```bash
npm install
npm run dev
```

The board has four categories. Each category has three point tiers:

- Difficult: `+20 / -15`
- Medium: `+10 / -10`
- Easy: `+5 / -5`

Pick a category and point tier to show a question. After revealing the answer, that question is marked as played and removed from the remaining count.
